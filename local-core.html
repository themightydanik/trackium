Local Core Publisher

Your compatible classic Core wallet signs locally. BlackBear is supported through the native APK only. No seed, wallet RPC credential or Gateway session is transferred. This foreground workflow stops when the MiniDapp closes. Android/WebView and real Mainnet operation still require live validation.

1. Pair the signed job

In the authenticated Gateway workspace, export an owner-approved Local Core job. Obtain the signing-key fingerprint there, through your trusted Gateway origin. Do not trust a fingerprint supplied with an unknown job file.

Not connected. No wallet commands executed.

2. Approve and prepare

Only a 0.001 self-transfer to the configured wallet is requested, with zero requested burn. The signed job caps total input selection. Inputs can be temporarily unavailable; PoW and signing-key uses are consumed. Do not assume the operation is risk-free or universally free.

Import the checkpoint into the authenticated Gateway workspace. It locks the final identity before broadcast and returns a signed acknowledgement. Gateway has not yet verified chain inclusion.

3. Checkpoint, publish & reconcile

Every retry first queries the known TxPoW ID. Only the saved artifact can be rebroadcast, at most three times. Transfer the result back to Gateway for independent node verification.
