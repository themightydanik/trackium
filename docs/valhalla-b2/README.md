# B2 integration evidence

Every route in these results was generated by Valhalla 3.6.3 through Gateway's customer-authenticated endpoint over the private Compose network. The result metadata is emitted by the probe. The geometry is generated and validated during the test. These files contain no customer data or request coordinates.

| Synthetic restriction graph | Car and truck routes use different fixture roads. Missing coverage and a disconnected route are also checked. | [Gateway results](restrictions-gateway.json) |

The corridor results demonstrate connectivity on the sampled roads. Expanded European coverage, live restrictions and HGV data completeness remain separate acceptance criteria.
